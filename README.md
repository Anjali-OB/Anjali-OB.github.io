## Deploy on GitHub Pages
1. Create a public repository named `Anjali-OB.github.io`.
2. Upload `index.html` and `Anjali_Khadke_Resume.pdf` (Add file > Upload files) and commit.
3. Go to Settings > Pages, choose Deploy from a branch, branch `main`, folder `/ (root)`, and Save.
4. After 1 to 3 minutes the site is live at https://anjali-ob.github.io.

## Update the site
Replace `index.html` (or the resume PDF) in the repository with the new version, keeping the same file names. GitHub redeploys automatically.

## Count visitors (optional)
1. Sign up free at [goatcounter.com](https://www.goatcounter.com) and pick a code.
2. In `index.html`, find the commented GoatCounter line near the bottom, remove the comment markers, and replace `YOURCODE` with your code.
3. Commit the change. The dashboard at `YOURCODE.goatcounter.com` shows views, countries, devices and referrers.
